# Tool Toán v1

Ứng dụng Android hỗ trợ học tập và trực quan hóa toán học với 2 không gian tách biệt:

- **Hình học không gian 3D (Oxyz):** 15 khối hình chuẩn (lăng trụ, chóp, hình trụ, hình nón, mặt cầu 3D đầy đủ), kéo đỉnh, dựng đường/mặt phẳng, tùy chỉnh độ nhạy 4 trục, và xuất file `.OBJ`, `.PNG`, `.JSON` ra thư mục ngoài.
- **Hình học phẳng 2D & Đồ thị hàm số (Oxy):** Zoom vô hạn độ chính xác cao, vẽ hàm số bất kỳ, thư viện hàm chia theo nhóm (**Mũ & Loga**, **Đa thức**, **Phân thức & Căn**, **Lượng giác**, **Đặc biệt**), nút bật/tắt đồ thị gốc `f(x)` và đạo hàm `f'(x)` riêng cho từng hàm.

## Tải file APK

Mỗi khi push lên nhánh `main`, GitHub Actions sẽ tự động biên dịch và đăng file cài đặt `tool-toan-v1-build-*.apk` tại mục **Releases** của kho lưu trữ.
